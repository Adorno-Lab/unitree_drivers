# unitree_drivers
Robot-agnostic, pImpl-based C++ classes wrapping the Unitree SDK for locomotion, arm/waist control, and low-level joint control and state/IMU telemetry across Unitree's robot lineup. Reusable building blocks for higher-level drivers (per-robot facades or sas::RobotDriver implementations), not a complete driver itself.
